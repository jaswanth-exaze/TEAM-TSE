QUICK REFERENCE

SQL’s logical execution order

  1. 01FROM

    Choose the source rows.

  2. 02JOIN

    Match related rows from other tables.

  3. 03WHERE

    Keep rows that meet a condition.

  4. 04GROUP BY

    Collect rows into groups.

  5. 05HAVING

    Filter groups after aggregation.

  6. 06SELECT

    Choose and calculate output columns.

  7. 07DISTINCT

    Remove duplicate output rows.

  8. 08ORDER BY

    Sort the remaining result.

  9. 09LIMIT

    Keep only the requested number of rows.

This is the logical order used to explain a query. A database engine may choose a different physical execution plan.
