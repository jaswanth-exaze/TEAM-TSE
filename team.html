Be the Next TSE to add your profile.

This page starts empty on purpose — no placeholder members, no fake data. It fills in exactly as people open pull requests. 

# 1. fork & clone the repo, then:
git checkout -b feature/add-your-name-profile

# 2. copy the template — this becomes YOUR page
cp -r team/members/_template team/members/your-name

# 3. edit team/members/your-name/index.html and style.css
#    however you like — this is real HTML/CSS practice

# 4. add your folder name to team/members/index.json

# 5. commit, push, and open a pull request
git add team/members/your-name team/members/index.json
git commit -m "Add your-name profile page"
git push origin feature/add-your-name-profile
